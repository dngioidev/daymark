# Reusable Engineering Templates

This directory provides standardized templates for pull requests, test plans, and task completion reports.

## Template Index

| Template | File | Purpose |
| :--- | :--- | :--- |
| **Pull Request** | [`pull-request.md`](./pull-request.md) | Standardized PR description format with Daymark invariant checklist and testing evidence. |
| **Test Plan** | [`test-plan.md`](./test-plan.md) | Matrix for automated checks, lifecycle scenario testing, and edge cases. |
| **Completion Report** | [`completion-report.md`](./completion-report.md) | Mandatory 4-part task wrap-up template matching [`.ai-configs/rules/completion-report.md`](../rules/completion-report.md). |
