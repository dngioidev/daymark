# Daymark Project Knowledge Hub

This directory is the single, canonical, high-density project documentation hub for **both human developers and AI coding agents**.

All technical facts, architecture models, algorithms, APIs, and conventions are defined once here in concise, token-efficient, and easily readable markdown.

## Document Index

| Document | Purpose & Scope |
| :--- | :--- |
| [**`architecture.md`**](./architecture.md) | Tri-mode topology (Desktop, Mobile PWA, Native widgets, Server), data flow, and sync model. |
| [**`codebase-map.md`**](./codebase-map.md) | Clean directory tree, critical modules, UI components, utilities, and server layout. |
| [**`specification.md`**](./specification.md) | Functional PRD, TypeScript schemas (`TaskItem`, `DailyDocument`), lifecycle rollover math, and markdown format. |
| [**`api-and-sync.md`**](./api-and-sync.md) | Express REST endpoints (`/api/health`, `/api/auth/login`, `/api/devices`, `/api/sync`), auth, and env vars. |
| [**`conventions.md`**](./conventions.md) | Build & run commands, non-negotiable Daymark engineering invariants. |
| [**`decisions.md`**](./decisions.md) | Architecture Decision Records (ADRs) explaining core design rationale. |
