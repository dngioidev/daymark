## Web
Open Settings and choose Appearance to adjust the theme, text size and colours. Changes preview immediately through the existing settings controls. Choose colours with enough contrast to keep labels and tasks readable. The header colours also apply to the desktop side menu, so inspect that menu when changing them.

Menu side selects Left or Right for the always-visible desktop rail. The content stays beside it, and Notes focus mode hides it temporarily. Background photos are selected on this device; use dim and blur controls to make text comfortable to read over them. Check both light and dark appearances after a substantial change. Synced preferences can follow you, while the photo files remain local to each device.
## Mobile
Open Settings, then Appearance, to choose a light or dark theme, text size, colours and a background photo. Settings preview as you adjust them. Use a readable text size and check task titles, menus and buttons after changing colours. Dim or blur a busy photo so the content stays clear.

Phones use the bottom tab bar, so Menu side affects the desktop layout when that preference is used on a wider screen. It does not turn the phone tabs into a side menu. Appearance preferences can sync, but background photo files are device-specific. Pick photos separately on each device and keep a copy of any image you want to reuse later.
