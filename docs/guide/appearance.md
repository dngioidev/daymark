## Web
1. Open **Settings** (the gear next to Search in the side menu) and choose **Appearance**.
2. Pick light or dark, a text size and colours. Changes preview immediately.
3. Use **Menu side** for a left or right side menu, and **Minimize menu** at the top of the menu to keep just the icons.
4. Add a background photo and use dim and blur to keep text readable.

Header colours also apply to the side menu, so check it after a change. The menu side and size stay on this device. Background photo files stay on each device; other preferences can sync.
## Phone
1. Tap the Settings gear in the top header, then **Appearance**.
2. Choose a light or dark theme, text size and colours.
3. Add a background photo, then dim or blur it so content stays clear.

Phones use the bottom tab bar, so Menu side only affects wider screens. Pick background photos separately on each device.
