## Web
Notes gives longer writing its own space. Open or create a note, organise it with folders, and use templates when starting repeated kinds of writing. The editor supports headings, lists, checkboxes, tables and code. Your content is stored as Markdown, so exported notes remain readable outside Daymark.

Paste a picture into a note to store it as a portable asset that can sync with the note. Mermaid code blocks render diagrams. Type double opening brackets to link to another note and use the suggestions to choose it. Focus mode hides surrounding navigation so the editor gets more room. Leave focus mode to restore it. Search finds note content alongside dated work.
## Mobile
Tap Notes in the bottom bar and select a note, or create one for longer writing. The editor provides formatting controls for headings, lists, checkboxes and other supported Markdown structures. Folders and templates help you keep related writing together. Save your changes before switching devices, then allow sync to exchange them when connected.

Notes can include pictures and Mermaid diagrams. Double-bracket links connect related notes and offer suggestions while typing. On a smaller screen, focus mode provides more room for the editor; leaving it brings navigation back. Pictures belong to your vault assets, so include them when making backups. Exported notes remain Markdown rather than being locked into the editor.
