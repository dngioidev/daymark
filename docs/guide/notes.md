## Web
Notes gives longer writing its own space. The editor supports headings, lists, checkboxes, tables and code, and your content stays Markdown. Paste a picture to store it as a portable asset, use Mermaid code blocks for diagrams, and type double opening brackets to link another note. Focus mode hides surrounding navigation.

Folders nest. Select All notes, Notes (top level) or a folder in the tree to filter the list; the actions button on a row offers New folder inside, Rename folder, Move folder and Delete folder (notes move up to the parent, never deleted). Drag a note or folder onto another folder to move it. Minimize folders keeps only icons.

With a note open, the Related panel suggests notes sharing distinctive words, calculated on your device. Link adds a wiki link; Not related hides the pair until you Restore it under Hidden suggestions. Switch List to Graph to see links, suggestions and tag lines, filtered by folder (including Root (no folder)), tag and Whole vault or Local.
## Mobile
Tap Notes in the bottom bar and select a note, or create one. The editor offers formatting controls for headings, lists, checkboxes and other Markdown. Notes can include pictures and Mermaid diagrams, and double-bracket links offer suggestions. Focus mode gives the editor more room; leaving it brings navigation back. Pictures belong to your vault assets, so include them in backups.

Folders nest. The Folders button above the notes list opens All notes, Notes (top level) and every folder with its count; the actions button on a row creates, renames, moves or deletes (notes move up to the parent). Inside a note, Move to folder files it under any folder without dragging.

The Related button, with its suggestion count, opens a sheet of notes that share distinctive words with this one. Link adds a wiki link; Not related hides it until you Restore it under Hidden suggestions. The graph, with List and Graph at the top of Notes, needs a tablet or wider screen.
