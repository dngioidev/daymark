## Web
Open your Daymark server in a modern browser and sign in. On a fresh device, choose an empty vault or sample data when offered. Your daily notebook is ready on Today. Use New task to capture something small, then tick it when finished. Notes provides a separate place for longer writing.

You can install the web app from your browser's installation menu. After the first successful load, the installed app can open offline. Keep a backup before clearing browser data: that browser profile holds your local vault. Sync connects other devices through your own server; it does not replace a backup.
## Mobile
Download the Android APK from Daymark's release page and install it. Android may ask you to allow installation from the browser or file manager you used. Updating over the existing app preserves its local data. Open Daymark, then connect to your server in Settings if you want multiple devices to sync.

You can also open the web app in your phone's browser and install it from the browser menu. Today is the starting screen, and the bottom tabs switch pages. Tap the plus button to capture a task. The app works offline; reconnect later to exchange changes. Make a backup before uninstalling or clearing app data.
