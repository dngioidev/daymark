## Web
1. Open your Daymark server in a modern browser and sign in.
2. On a fresh device, choose an empty vault or sample data when offered.
3. Install the web app from your browser's install menu. After the first load it opens offline.

That browser profile holds your local vault, so make a backup before clearing browser data. Sync connects other devices through your own server.
## Phone
1. Download the Android APK from Daymark's release page.
2. Allow installation from your browser or file manager if Android asks.
3. Open the app and connect your server in **Settings → Sync**.

Updates signed with the same key keep your data. Back up before uninstalling or clearing app data. You can also install the web app from your phone's browser menu.

**One-time switch from a debug build to a release build:** sync or back up first, uninstall the debug app, install the signed APK, then sign in again. Android refuses to update an app signed with a different key.
