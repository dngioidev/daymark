## Web
1. Open **Today**. Use the day arrows to browse other days.
2. Tick a task to finish it. Open its title for details and history.
3. Use the task menu to move it or record when it was really done. Choose **Event** in New task to add an appointment or commitment alongside tasks.

Unfinished tasks carry forward according to their status settings. Their age stays visible, so repeatedly postponed work is easy to spot. Finishing a later copy closes earlier copies as Done later.

In **Settings → Old-task warnings**, **Task aging counts** chooses Weekdays, Weekends or All week (the default). Only those days add to task age. The choice syncs and does not change carry-forward. Event warnings are configured separately in **Settings → Events**.
## Phone
1. Open the **Today** tab.
2. Tap a checkbox to finish a task, its title for details, or its menu for more actions.
3. Use the date controls to view another day. The plus button opens New task; choose **Event** to capture an appointment or commitment.

When a new day begins, unfinished work carries forward with its history and age. Finishing the later copy closes earlier ones as Done later. Use Backlog for ideas that should wait without aging.

**Settings → Old-task warnings → Task aging counts** chooses weekdays, weekends or all week. **Settings → Event warnings** controls advance warnings. Events appear with open tasks but have no completion or overdue state, aging or carry-forward; checklist items can be checked.
